Recommendation on the ₹10 Cr

  1. Don’t commit ₹10 Cr to any growth lever yet. Activity doesn’t move recovery, so more agents / telephony / field visits ≈ ₹0 incremental.
  2. Spend ₹30–40 L now on a randomized holdout (~3% no-contact control, 10–12 weeks) to measure true lift. Highest-ROI action available.
  3. If forced to allocate: AI-voice / digital automation as a cost play — hold recovery flat, cut cost/₹-recovered ~₹4–7 Cr/yr; payback 18–30 mo. Downside if a small human-touch effect exists: recovery −1–3%.
